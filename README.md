# SkyClinic — Website System
Repozytorium projektu strony skyclinic.pl
Stack: React + Tailwind CSS, budowane w Lovable.

## Struktura
- docs/ — specyfikacja, architektura, zasady
- content/ — teksty do strony (100 podstron .md)
- lovable/ — prompty i materiały dla Lovable
- brand/ — kolory, typografia, compliance
- assets/ — loga i zdjęcia
- ops/ — workflow i checklisty
